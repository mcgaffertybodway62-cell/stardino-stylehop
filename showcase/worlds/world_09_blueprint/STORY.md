## 一句话故事

史莱姆化作一张带 CAD 尺寸标注的 2D 白线剖面图落在普鲁士蓝晒图纸上，向右追星却一头撞上未完工的图纸中缝边界；它笃笃敲击纸缝，随后用 **2D 圆形表盘 + 单根指针**做视线扫描（**成片没有 3D 球面转头、没有准星、没有图框高亮**），闭眼发射意念脑波补全图纸参数——整张蓝图从中缝哗啦撕开，右侧 2D 线框拔地生长为 3D 马卡龙水晶浮空岛！**26.0s 起 3D compass-star（四角星 + 双环）越界落岛**（不是两脚圆规，也没有可见的 2D 抛投），27.0–30.0s 3D 史莱姆成形，欢跳环顾后乘通天星光柱冲破云霄！

## 五幕故事正文与动作编排（34.0s，对应 [`07_choreography_34s_timeline.js`](split/07_choreography_34s_timeline.js)）

**一、Act 1 · 蓝图降临与右界碰壁受阻（0.0 ~ 2.5s）**  
普鲁士蓝晒图纸铺满全屏（此时 `splitRatio` 位于最右端，全屏皆为 2D 工程蓝图）。2D 白线史莱姆从图纸左侧坐标原点轻快地向右连跳进场，准备冲向图纸右侧的浮岛线框——不料"咚！"地一声，一头撞在图纸中缝的垂直边界线上，整张圆脸被撞得横向压扁回弹（`flat` 眼），头顶尺寸标注线剧烈抖动。

**二、Act 2 · 笃笃敲缝与歪头疑惑（2.5 ~ 5.2s）**  
史莱姆稳住身形，凑到图纸中缝边界前，用身体轻轻往前"笃、笃"敲了两下纸缝（激起两圈小型 2D 制图波纹）。为什么过不去？它疑惑地歪起脑袋（`curious` 不对称大小眼：近端眼放大 `1.16x`、远端眼微眯 `0.76x`），意识到右边的浮岛还只是没有厚度的 2D 未完工线稿！

**三、Act 3 · 2D 表盘式视线扫描（5.2 ~ 14.8s）**  
史莱姆站在中缝前，画面用**圆形表盘 + 单根指针**表现“审图视线”（成片没有 3D 球面转头、没有 `gazeReticle` 准星、没有图框高亮）：
1. **5.2 ~ 8.2s**：指针/眼位停在表盘**右上方**（不是旧稿写的左上 `ELEVATION E-1` 方向）；
2. **9.2 ~ 11.2s**：指针/眼位移到表盘**左侧**；
3. **12.2 ~ 14.2s**：指针/眼位移到表盘**下方/右下**；14.8s 前后双眼亮成 `sparkle` `✦ ✦`。
**成片没有出现旧稿的 `headYaw = -0.82 / -0.88` 大幅 3D 转头，也没有三块图框逐行高亮。**

**四、Act 4 · 意念脑波补全图纸 · 撕开中缝拔起 3D 马卡龙浮岛（14.8 ~ 23.2s）**  
史莱姆闭上双眼（`flat` 专注蓄力态），头顶荡开一圈圈高频白色**意念制图脑波环（`brainwaveIntensity`）**，将右下角图签栏的 `TITLE BLOCK` 彻底点亮为翠绿通过态（`APPROVED ✓`）！  
- **19.2 ~ 23.2s（撕开蓝图 · 2D 拔起为 3D）**：伴随着清脆的撕纸与生长冒泡声，画面中央的正弦波浪撕裂分界线**从右向左大幅拉开**（`splitRatio` 左移）！分界线右侧，原本扁平的 2D 白线浮岛在柔和的晴空光影中，按 `extrude: 0 → 1`（带 `easeOutBack` 弹簧超调）一座接一座拔地而起——长出多面体马卡龙岩壁、薄荷绿草坪、樱花树、风车与中央的星光升降柱！

**五、Act 5 · compass-star 越界 → 3D 史莱姆成形 → 星光柱飞升（23.2 ~ 34.0s）**  
3D 浮岛建成了，但史莱姆自己还在左边的 2D 图纸上，怎么过去？
1. **23.2 ~ 26.0s（2D 史莱姆停留在图纸侧）**：**成片没有出现“摘下头顶精密工程圆规信物 / 跨界抛投”的可见动作**；2D 表盘与指针继续转动，右侧 3D 浮岛已经成型；
2. **26.0 ~ 27.0s（3D compass-star 越界）**：`heroCompassStar`（四角星 + 双环）从撕裂边界越到右侧，落到中央浮岛并点亮星光柱；**不是两脚圆规**；
3. **27.0 ~ 30.0s（3D 史莱姆成形）**：3D 马卡龙史莱姆在中央浮岛逐渐成形，`30.0s` 起清晰可见；成片没有明显的“2D 坍缩成光点”过程；
4. **30.0 ~ 31.5s（环顾/轻跳）**：3D 史莱姆在草坪上左右环顾，欢跳幅度较小；
5. **31.5 ~ 34.0s（跃入星光柱）**：史莱姆跳入中央通天星光柱，光柱爆发，带着 compass-star 垂直冲入云霄，无缝交接第 10 关。
